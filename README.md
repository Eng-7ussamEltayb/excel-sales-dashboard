# لوحة مبيعات Excel
## Excel Sales Dashboard

**Portfolio Demo Project** | المستوى: **أساسي** | المؤلف: [Eng-7ussamEltayb](https://github.com/Eng-7ussamEltayb)

### الفكرة
توليد ملف Excel احترافي من بيانات مبيعات مع تجميع حسب المنطقة والشهر، ودليل ربط سريع مع Power BI.

### التقنيات
Python, pandas, openpyxl, Excel, Power BI

### المميزات
- توليد workbook متعدد الأوراق
- مخطط أعمدة حسب المنطقة
- دليل Power BI مختصر

### طريقة التشغيل
1. pip install -r requirements.txt
2. python build_workbook.py
3. افتح output/sales_dashboard.xlsx

### هيكل المشروع
```
build_workbook.py
data/sales.csv
docs/POWER_BI_GUIDE.md
README.md
```
